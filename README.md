# Automated Testing Project for SVVT

This repository contains an automated testing project implemented using **Selenium**, created for the purpose of understanding **Software Verification, Validation, and Testing (SVVT)** concepts.

## Project Overview

The automated tests are written for an already implemented web application called **Movies Watchlist**.  
The goal of this project is to validate application functionality, verify expected behavior, and practice test automation techniques.
